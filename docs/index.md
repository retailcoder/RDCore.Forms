# RDForms

RDForms is the form toolkit of the RDCore platform: cross-platform forms for RD-VBA, built on Avalonia and designed for MVVM. It imports the forms of VB6 projects and the UserForms of VBA projects.

| Package | Role |
|---|---|
| `RDCore.Forms` | The form model, with no UI dependency, and the readers that import a form into it. |
| `RDCore.Forms.Avalonia` | The controls, and the window built from the model. |

> [!NOTE]
> RDForms is in pre-alpha development. Nothing is published yet, and the API will change.

The API reference is generated from the libraries' xmldocs.
